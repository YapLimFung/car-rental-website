# ATAS Car Rental System

A centralized web application designed to simplify car rentals, eliminate manual paperwork, and enable seamless 24/7 online vehicle bookings[span_0](start_span)[span_0](end_span). The platform serves both rental customers and administrative staff through specialized interfaces[span_1](start_span)[span_1](end_span).

## Key Features

### For Customers
* **Account Management:** User registration and login functionality[span_2](start_span)[span_2](end_span).
* **Browse & Book:** View vehicle availability, inspect vehicle specs/rates, and submit 24/7 rental reservations[span_3](start_span)[span_3](end_span).
* **Contact & Locations:** View available rental locations across Malaysia and submit direct inquiries[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).

### For Staff & Admin
* **Executive Dashboard:** High-level summary displaying vehicle availability, rental metrics, and active bookings[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span).
* **Vehicle Management:** Add, edit, view, or remove fleet vehicles from the database[span_8](start_span)[span_8](end_span).
* **Booking Management:** Complete control over rental reservations, statuses, and scheduling[span_9](start_span)[span_9](end_span).
* **Customer Management:** Maintain customer accounts, loyalty tiers, and status details[span_10](start_span)[span_10](end_span)[span_11](start_span)[span_11](end_span).
* **Security & Access Control:** Role-based access restriction implemented via PHP sessions with strict data validation[span_12](start_span)[span_12](end_span).
