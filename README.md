# ATAS Car Rental System

A centralized web application designed to simplify car rentals, eliminate manual paperwork, and enable seamless 24/7 online vehicle bookings. The platform serves both rental customers and administrative staff through specialized interfaces.

---

## Key Features

### For Customers
* **Account Management:** User registration and login functionality.
* **Browse & Book:** View vehicle availability, inspect vehicle specs/rates, and submit 24/7 rental reservations.
* **Contact & Locations:** View available rental locations across Malaysia and submit direct inquiries.

### For Staff & Admin
* **Executive Dashboard:** High-level summary displaying vehicle availability, rental metrics, and active bookings.
* **Vehicle Management:** Add, edit, view, or remove fleet vehicles from the database.
* **Booking Management:** Complete control over rental reservations, statuses, and scheduling.
* **Customer Management:** Maintain customer accounts, loyalty tiers, and status details.
* **Security & Access Control:** Role-based access restriction implemented via PHP sessions with strict data validation.

---

## Tech Stack

* **Frontend:** HTML5, CSS3
* **Backend:** PHP
* **Database:** MySQL
